# Sex-biased admixture in six 1000 Genomes populations

This folder contains the instructions to reproduce the results (tables and figures) of the
**Results** section of the `tracts 2.0` paper.

We fit three-way (EUR, AMR, AFR) sex-biased admixture models jointly on autosomal and X chromosome
local ancestry tracts for the six admixed populations of the 1000 Genomes Project Phase 3: ACB,
ASW, CLM, MXL, PEL and PUR. For each population, a single-pulse model and a second, more complex
model are fitted:

| Population | Single-pulse model | Second model |
|------------|--------------------|--------------|
| ACB | `ppp` | `ppx_xxp_pxx` (three pulses) |
| ASW | `ppp` | `ppx_xxp_pxx` (three pulses) |
| CLM | `ppp` | `ccc` (continuous migration) |
| MXL | `ppp` | `ccp` (continuous EUR and AMR migration, AFR pulse) |
| PEL | `ppp` | `ccc` (continuous migration) |
| PUR | `ppp` | `cpc` (continuous EUR and AFR migration, AMR pulse) |

## Folder contents

- `models/`: demographic models in the Demes-based YAML format used by `tracts`.
- `ACB/`, `ASW/`, ...: one folder per population, containing a driver file `<POP>_<model>.yaml`
  (data, model, starting parameters and optimization options) and a short Python launcher
  `<POP>_<model>.py` for each model. Each run writes its results to
  `<POP>/output_<model>/<YYYYMMDD_HHMMSS>/`.
- `run_all.sh`, `summarize_output.sh`, `produce_plots.sh`: the three scripts described below.

Only the models listed in the table above are used in the paper.

## Reproducing the results

### 1. Install `tracts`

From the root of the repository:

```bash
pip install .
```

### 2. Download the data

The local ancestry calls (RFMix, generated by the 1000 Genomes Project) and the sample metadata are
downloaded with the scripts in `example/data/`:

```bash
cd example/data             # from the root of the repository
bash data_download.sh       # local ancestry archives of the six populations (downloaded and extracted)
bash metadata_download.sh   # sample panel (population, sex) and list of related individuals
cd ../3pops_sexbiased
```

The lists of individuals (unrelated individuals, and males for the X chromosome) are already written
in the driver files. `example/data/list_unrelateds_males.sh` is the helper that was used to build them.
For ASW, four individuals with more than 20% ancestry from the Americas are also excluded (see the
paper).

### 3. Run the inference: `run_all.sh`

```bash
bash run_all.sh
```

Runs the inference for every population and model in the table above, in parallel (up to
`MAX_WORKERS` runs at a time). Populations can be switched on or off with the `RUN_<POP>` flags at the
top of the script, and the models with the `<POP>_MODELS` arrays. Each run creates a new
timestamped output folder, so previous results are never overwritten.

### 4. Summarize the results and produce the tables: `summarize_output.sh`

```bash
bash summarize_output.sh -s all
```

Prints, for every population and model, the number of individuals and the log-likelihood of the
latest run, together with warnings (for example, if an earlier run reached a better likelihood).
With `LATEX_FORMAT=1` (default), it then prints the LaTeX tables of the paper:
observed and predicted ancestry proportions, and best-fit parameters of both models.

### 5. Produce the figures: `produce_plots.sh`

```bash
bash produce_plots.sh
```

Regenerates the figures from the existing outputs, without re-running the inference, and saves them
in `plots/`: observed and predicted tract length distributions comparing both models
(`<POP>_autosomes_model_comparison.pdf`, `<POP>_allosomes_model_comparison.pdf`), migration matrices
(`<POP>_<model>_migration_matrices.pdf`) and admixture plots.

**Note:** `summarize_output.sh` and `produce_plots.sh` use the **latest** run of each model, not the
one with the best likelihood. If the latest run is unfinished (still running or crashed), that model
is skipped with a message. For `produce_plots.sh` only, running
`USE_LATEST_COMPLETE_RUN=1 bash produce_plots.sh` uses the most recent complete run instead.
