.. _example-asw:

ASW population
==============

This page collects the example analyses for the ASW population. They illustrate how to use ``tracts`` and are not the analyses presented in the paper: they use trio-phased local ancestry calls, whereas the paper uses population-phased calls. To reproduce the analysis of the six 1000 Genomes populations presented in the paper, see the folder `example/3pops_sexbiased <https://github.com/gravelLab/tracts/tree/devel/example/3pops_sexbiased>`_ of the GitHub repository.
